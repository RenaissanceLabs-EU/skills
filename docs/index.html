How it works

The skill is one Python file and a page of instructions. The file builds the index in three passes and then queries it. Everything except search by meaning runs on the Python standard library.

  1. Crawl

    Reads the Hub's dataset listing, 1,000 records per request, and stores each card's tags, license, sizes and description.

    crawl

  2. Enrich

    Asks the dataset viewer for exact row counts and column names where the card does not declare them.

    enrich --all

  3. Embed

    Writes a 256-number vector for each dataset from its name, description, tags and columns. One minute on a laptop CPU.

    embed

  4. Search

    Filters in SQL, matches keywords in a full-text index, or ranks all 1.15 million vectors against the question.

    search

What the first crawl showed

Most of the Hub is thinly described. Of the 1,151,565 public datasets on 26 November 2026, before any enrichment:

  • have a dataset card69%
  • declare a license37%
  • declare their columns30%
  • declare a row count30%

The dataset viewer has column data for roughly another 416,000 datasets. The enrich pass collects it, one request per dataset.

Install

Clone the repository and link the skill into Claude Code. Other agents can read SKILL.md directly.

git clone https://github.com/RenaissanceLabs-EU/skills.git
ln -s "$PWD/skills/hf-dataset-search" \
      ~/.claude/skills/hf-dataset-search

Build the index once. It lands in ~/.cache/hfmeta/ unless HFMETA_DB points elsewhere.

cd skills/hf-dataset-search
python3 scripts/hfmeta.py crawl
uv run -q scripts/hfmeta.py embed

Requirements: Python 3.9 or later. Search by meaning also needs uv, which installs numpy and model2vec on first use. No Hugging Face account is needed; set HF_TOKEN to reach gated datasets you have access to.

Limits

  • Shape is a guess. It reads column names, so a dataset with unusual names or no known columns has no shape. Pair a shape filter with a keyword search.
  • License class is a filter. It buckets the tag the uploader chose. Read the license before training on anything.
  • Search by meaning is a wide net. The embedding model is small and runs on CPU. Short topic phrases work best, and keyword search sometimes ranks better.
  • The index is a snapshot. crawl --update fetches what changed. Datasets deleted from the Hub stay until the index is rebuilt.
  • Downloads measure attention. They say nothing about whether the rows are any good.
